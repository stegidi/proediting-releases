# ProEditing

Editor foto e video per Mac. Richiede un Mac Apple Silicon con macOS 15 o successivo.

## Installazione
1. Scarica `ProEditing.zip` dall'[ultima release](https://github.com/stegidi/proediting-releases/releases/latest).
2. Estrai lo zip e sposta `ProEditing.app` in Applicazioni.
3. Alla prima apertura, se macOS la blocca: Impostazioni di Sistema → Privacy e sicurezza → Apri comunque.

## Aggiornamenti
L'app controlla a ogni apertura. Quando c'è una nuova versione, premi **Installa**.
Puoi controllare anche dal menu ProEditing → Controlla aggiornamenti…
